# shensha.md —— 神煞：只展示少量吉神

> 版本：v1.1（2026-10-29，mingli-expert）。依据用户决定：神煞**只展示吉神**；天乙、太极、文昌**日干、年干都查**（v1.1 用户决定，未采纳“只查日干”的推荐）。
> 输入：calendar.md 排出的四柱（或三柱）。输出：吉神列表（名称 + 所在位置）。
> 规则编号以 `SS-` 开头。

---

## 0. 总原则（SS-SCOPE）

1. **只做展示和点缀，不参与任何判定。** 吉神不改变五行力量、旺衰等级、格局、喜用忌神、大运流年评分（strength.md / yongshen.md / report-sections.md 的计分里都不得引用本文件的输出）。
2. **不展示任何凶煞**（羊刃、劫煞、亡神、孤辰寡宿、白虎、丧门、桃花/咸池等一律不算、不存、不显示）。驿马、华盖这类“吉凶两说”的也不展示。
3. **不展示纳音、空亡**（含“旬空”），也不在报告里提到。
4. **宁少勿多**：v1 只选 4 个，都是古籍里查法稳定、各家分歧小、意义正面的。
5. **没有吉神时什么都不显示**，不得出现“命中无贵人”“缺少吉神”之类的话。
6. **免费结果页不展示吉神**，只在付费报告第 0 章、第 3 章出现（§3）。

选择标准与取舍：神煞体系在《渊海子平》《三命通会》里有上百个，查法版本多、吉凶常因组合而变，子平正宗（《子平真诠》《滴天髓》）本就主张“不以神煞论命”。本项目只把少量吉神当作文化点缀，让报告有“传统味道”，但不让它影响任何结论——这样既保留可读性，又不引入不可审查的判断。

## 1. 选用的 4 个吉神与查法

查法（用户 2026-10-29 决定）：
- 天乙、太极、文昌：传统上日干、年干均可起查，本项目**两者都查**，各自查四柱全部地支（含本柱地支）。
- 月德：按**月支**查天干，不涉及日干/年干，不变。
- 已知影响：日干、年干兼查后，绝大多数命盘至少有 1 个吉神（cases.json 19 个案例全部有），所以吉神**没有区分度**，这也是它只做点缀、不参与任何判定的又一理由。展示数量在 §3 加了上限。

## 2. 计算与输出（SS-OUTPUT）

```
jishen = []
for 吉神 in [天乙贵人, 月德贵人, 文昌贵人, 太极贵人]:      # 固定展示顺序
    hits = {}                                            # 位置 → 起查来源列表
    if 吉神 == 月德贵人:
        for 天干位置 命中: hits[位置] = ["月支"]
    else:
        for 起查 in [日干, 年干]:                           # 日干在前
            for 地支位置 命中: hits.setdefault(位置, []).append(起查)
    if hits:
        jishen.append({"name": 吉神,
                       "hits": [{"pos": p, "by": hits[p]} for p in 按 年→月→日→时 排序]})
```
- **去重**：同一个吉神命中多个位置只算**一条**；同一地支被日干、年干同时查到，只出现**一次**，`by` 记为 `["日干", "年干"]`。
- 日干与年干相同（如 C04 乙亥年乙巳日）时，所有命中的 `by` 都是 `["日干", "年干"]`。
- 年干查到年支本身也算（各柱地支一律参与）。
- 时辰未知：不查时柱；不因为时柱可能有吉神而提示“可能有贵人”。年干、日干照常起查。
- 交节日 + 无时辰 + 用户选“不确定”（calendar.md CAL-NOHOUR、案例 C19）：两组年月柱各查一次（年干也不同），**只展示两组都命中的“吉神名 + 位置”**（`by` 只保留两组都成立的来源；实际上两组年干不同，共有的命中通常只来自日干），输出到 `jishen_display`，完整结果放 `jishen` 供测试。
- 晚子时（23:00–23:59）：按早晚子时派排出的四柱查（日干仍是当日日干，时支是子）。

输出示例（案例 C12：乙丑 己卯 戊申 癸丑；日干戊、年干乙）：
```json
[
  {"name": "天乙贵人", "hits": [{"pos": "年支", "by": ["日干"]}, {"pos": "日支", "by": ["年干"]}, {"pos": "时支", "by": ["日干"]}]},
  {"name": "文昌贵人", "hits": [{"pos": "日支", "by": ["日干"]}]},
  {"name": "太极贵人", "hits": [{"pos": "年支", "by": ["日干"]}, {"pos": "时支", "by": ["日干"]}]}
]
```

## 3. 展示位置（SS-DISPLAY）

**吉神只在付费报告中展示**（用户 2026-10-29 决定：免费结果页不显示任何吉神标签或文字）。

| 位置 | 形式 | 说明 |
|---|---|---|
| 免费结果页 | **不展示** | 免费页只有四柱八字、五行强弱图、日主旺衰、喜用神/忌神（report-sections.md R-FREE） |
| 付费报告 · 第 0 章命盘总览 | 命盘表下方一张小表，每个吉神一行：名称、所在位置、起查来源、一句释义（§4）。例：“天乙贵人 ｜ 年支（年干查得）、月支（日干查得） ｜ 传统上……” | 同一位置日干、年干都查到时写“日干、年干均查得”，只列一次。表下固定灰字：“吉神为传统文化中的象征性说法，以日干、年干查得，多数命盘都有一个或几个；本报告的旺衰与喜用判断不使用它。” |
| 付费报告 · 第 3 章性格与天赋 | 可选槽位 CH3-SHENSHA，**最多 1 段、60–100 字**，只写按固定顺序排在最前的那个吉神 | 素材见 texts/，触发字段 `shensha_first`；正文不写来源和位置（第 0 章已列） |
| 其他章节 | **不出现** | 大运、流年、分领域、喜用一律不提吉神，避免读者以为它影响了结论 |

数量控制（因日干、年干兼查后几乎人人都有吉神）：
- 第 0 章最多列 4 行（即全部 4 个吉神，每个一行，多个位置合并在同一行）；不显示“共 N 个”之类计数。
- 第 3 章始终最多 1 段，不论命中几个。
- 其他任何地方不得汇总吉神数量或据此做比较。

## 4. 释义与措辞约束（SS-WORDING）

固定释义（第 0 章表中显示，代码常量，不变体）：
| 吉神 | 一句释义 |
|---|---|
| 天乙贵人 | 传统上被视为最重要的吉神，象征容易得到他人帮助与提携。 |
| 月德贵人 | 传统上象征为人宽厚、处事平顺。 |
| 文昌贵人 | 传统上象征聪敏好学，利于读书与考试。 |
| 太极贵人 | 传统上象征悟性好，对哲理、玄学、研究类事物有兴趣。 |

约束：
1. 必须带“传统上”“象征”“古人认为”之类限定语，**不得**写成事实承诺：禁止“必有贵人相助”“考试一定顺利”“逢凶化吉”“保平安”。
2. 不与年份挂钩：不写“某年贵人到”“贵人年”。
3. 不比较多少、不计数：不写“你有 3 个贵人”“比一般人多”“贵人多福气大”“双贵人”；同一吉神由日干、年干都查到，也不得写成“加倍”“格外有力”。
4. 不与喜忌冲突：吉神段落里不出现五行喜忌、不出现“但是”“可惜”之类转折去引出负面内容。
5. 不导流消费：不出现“佩戴”“摆放”“开运”“化解”。
6. 以上禁用表述并入 report-sections.md R-CHECK 禁用词表。
