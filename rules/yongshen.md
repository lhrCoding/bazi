> 版本：v1（2026-10-27，mingli-expert）
> 输入：strength.md 的输出（level、special、gods、power、月支）。
> 输出：用神 1 个五行、喜神 1–3 个、忌神 1–3 个、闲神（其余），以及触发规则编号和一句人话依据。

## 0. 总原则与优先级

| 优先级 | 方法 | 作用 | 出处 |
|---|---|---|---|
| 1 | **格局（从格/专旺）** | 命中特殊格局时，整套喜忌换成“顺势” | 《滴天髓》从象、一行得气；《子平真诠》弃命从财/从杀 |
| 2 | **扶抑** | 主干：弱则扶（印、比劫），强则抑（食伤、财、官杀） | 《子平真诠》《滴天髓》“旺则宜泄宜伤，衰则喜帮喜助” |
| 3 | **调候** | 修正：冬生缺火、夏生缺水时补进喜神；中和时可直接当用神 | 《穷通宝鉴》 |
| 4 | **通关** | 修正：两强相克时，补一个通关五行到喜神（不能和扶抑方向冲突） | 《滴天髓》“通关” |

**判定顺序固定为：格局 → 扶抑 → 用神缺位互换 → 调候 → 通关 → 计算闲神。** 每一步只能做本文写明的改动。
神煞（含 shensha.md 展示的吉神）、纳音、空亡不参与喜忌判定的任何一步。

> v1.1（2026-10-30）：澄清 Y-TH-NEUTRAL-OVERRIDE——原用神保留为第一喜神，“冬删水 / 夏删土”只作用于原喜神列表（§4），新增案例 C20。
> v2（2026-10-29）：本文件规则内容不变；用户确认保留“用神缺位互换”（§3.3）与“只认真从”。`basis` 依据句改由素材库拼装引擎按模板生成（见 report-sections.md、texts/README.md）。

> 关于流派的选择：现代主流（含大部分排盘软件）以扶抑为主；《穷通宝鉴》纯调候派在冬夏生人上常与扶抑结论不同。本项目选“扶抑为主、调候修正”，理由：扶抑能覆盖所有命局、逻辑可以解释给普通人听（“你偏弱，所以需要帮扶”）；调候只在“明显过寒/过燥”时介入，避免两套体系互相打架。

## 2. 特殊格局（Y-CONG / Y-ZHUANWANG）

| special | 用神 | 喜神 | 忌神 |
|---|---|---|---|
| 从财 | 财 | 食伤 | 比劫、印 |
| 从杀 | 官杀 | 财 | 印、比劫、食伤 |
| 从儿 | 食伤 | 财 | 印、官杀 |
| 从势 | 财 | 食伤、官杀 | 印、比劫 |
| 专旺 | 比劫 | 印、食伤 | 官杀、财 |
| 从强 | 印 | 比劫 | 财、食伤、官杀 |

- 从财忌比劫在前：比劫夺财，最破格。
- 从杀忌食伤：食伤制杀，与印化杀同样破坏“从”的格局（《滴天髓》论从杀“喜财生杀，忌食伤制、印绶化”）。
- 从儿忌官杀、不忌比劫：食伤与官杀相战；比劫能生食伤，列闲神。
- 从势用财：财居食伤与官杀之间，能“通”两方（《滴天髓》任铁樵注从势“宜行财地”）。
- 专旺喜食伤：一行得气，喜秀气流行（泄）；忌官杀逆其旺势。
- 从强（印多）忌食伤：《滴天髓》“从强……食伤运必凶（印来克之），财官运大凶”。
- 特殊格局**跳过**调候、通关修正（顺势为先）。

## 3. 扶抑（Y-FY）

### 3.1 偏弱：level ∈ {身弱, 中和偏弱}
找异党中力量最大的一方 D（并列时优先级：官杀 > 食伤 > 财）：

| D | 用神 | 喜神 | 忌神（按害处排序） | 规则 | 古法说法 |
|---|---|---|---|---|---|
| 官杀 | 印 | 比劫 | 官杀、异党第二强 | Y-FY-W-SHA | 杀重用印化杀（杀印相生） |
| 食伤 | 印 | 比劫 | 食伤、异党第二强 | Y-FY-W-SHI | 食伤泄重用印制之 |
| 财 | 比劫 | 印 | 财、异党第二强 | Y-FY-W-CAI | 财多身弱用比劫（印怕财坏） |

异党第三强列为闲神。

### 3.2 偏旺：level ∈ {身旺, 中和偏旺}
找同党中力量较大的一方 F（比劫 ≥ 印 则 F=比劫）：

| 条件 | 用神 | 喜神 | 忌神 | 规则 | 古法说法 |
|---|---|---|---|---|---|
| F = 印 | 财 | 食伤 | 印、比劫 | Y-FY-S-YIN | 印旺用财破印 |
| F = 比劫 且 官杀力量 ≥ 1.0 | 官杀 | 财 | 比劫、印 | Y-FY-S-BI-GUAN | 比劫重用官杀制之 |
| F = 比劫 且 官杀力量 < 1.0 | 食伤 | 财 | 比劫、印 | Y-FY-S-BI-SHI | 无官杀则用食伤泄秀 |

官杀力量 ≥ 1.0 ≈ “官杀透干有根或坐实一个地支”，太弱的官杀制不住比劫。

### 3.3 用神缺位互换（Y-SWAP）——有争议，本项目的选择
若扶抑选出的用神在原局力量 = 0（四柱完全不见），且第一喜神力量 ≥ 1.0，则**用神与第一喜神互换**。

- 例：C12 戊土杀重，扶抑取印（火）为用，但原局一点火都没有，而比劫（土）有 2.23 → 用神改为土，火降为第一喜神。
- 理由：《子平真诠》强调用神要从原局取；对用户来说“用神就在你命里”也更好解释。被换下的五行仍是喜神，大运流年遇到照样算好运，**喜忌方向不变，只是标签顺序变**。
- 不采用此规则的流派会把“原局不见的五行”照样定为用神（指望运来补）。如用户偏好这种，删除此步即可，喜忌集合不受影响。

## 4. 调候修正（Y-TH）

```
月支 ∈ {亥, 子, 丑} → 需要 火（寒）
月支 ∈ {巳, 午, 未} → 需要 水（燥）
触发条件：所需五行 power / total < 0.10，且不是特殊格局
```
| 情况 | 处理 | 规则 |
|---|---|---|
| 所需五行已是用神或喜神 | 不变，记录“调候与扶抑一致”（报告可加强语气） | Y-TH-AGREE |
| level 为 中和偏弱/中和偏旺 | **调候五行直接做用神**；原用神降为第一喜神并**保留**；从**原来的喜神列表**中删去“克调候五行”的那一行（冬删水、夏删土），这一删除不作用于被降级的原用神；从忌神中删去调候五行 | Y-TH-NEUTRAL-OVERRIDE |
| level 为 身弱/身旺 | 用神不变；调候五行**追加到喜神末尾**，并从忌神中删除 | Y-TH-ADD-XI |

- v1.1 澄清（用户 2026-10-30 决定）：Y-TH-NEUTRAL-OVERRIDE 的执行顺序为 ① 记下原喜神列表 X；② 调候五行设为用神；③ 从 X 中删去克调候五行的那一行；④ 新喜神 = [原用神] + 处理后的 X；⑤ 忌神中删去调候五行。所以原用神恰好是水（冬）或土（夏）时，它仍是第一喜神，不会变成闲神。理由：扶抑是主干，调候只是在中和命局里接管“谁打头”，不应把扶抑选出的用神整个抹掉。案例：C20（冬季中和偏弱甲木，扶抑取水为用 → 用火、喜水木）；C16 在新旧读法下结果相同。
- 出处：《穷通宝鉴》冬月“丙火为尊”（如十二月乙木“专用丙火”）、夏月“壬癸为要”（如五月壬水“取癸为用、庚辛为佐”）。
- 为什么只在“中和”时让调候当用神：身弱/身旺时扶抑需求更急，调候只能当辅助；中和命局扶抑需求不强，调候成了主要矛盾。
- 春秋两季（寅卯辰、申酉戌）v1 不做调候。
- 已知张力：冬季身弱的木日主，扶抑取水（印），调候又要火，两者都会进喜神。这是古法里本来就存在的取舍，报告里要说清楚“水是根本、火是辅助”，不能写成矛盾。

## 5. 通关修正（Y-TG）

```
取 power 最大的两个五行 A、B（并列按 木火土金水 顺序）
若 A 克 B（或 B 克 A），且两者各自 ≥ total × 25%：
    通关五行 Z = 攻方所生（例：金克木 → 水通关）
    只有当 Z 与扶抑方向一致时才加入喜神末尾：
        偏弱命局：Z 必须是 印 或 比劫
        偏旺命局：Z 必须是 食伤、财 或 官杀
    且 Z 不在忌神、不是用神
```
- 方向不一致时只在 `notes` 记录“两强相战，Z 可通关，但与扶抑方向冲突，未采用”。
- 理由：通关是修正，不能把“身弱的人”的财星变成喜神。

## 6. 闲神与输出

```
闲神 = 五行全集 − {用神} − 喜神 − 忌神
保证：用神、喜神、忌神、闲神两两不重复，合起来正好五个五行
```

输出（以 C16 为例）：
```json
{
  "yong": "火",
  "xi": ["木"],
  "ji": ["土", "金"],
  "xian": ["水"],
  "rules_hit": ["Y-FY-W-CAI", "Y-TH-NEUTRAL-OVERRIDE"],
  "basis": [
    "乙木生于丑月，同党占 42%，属中和偏弱，原本取比劫木帮身（财多身弱）。",
    "丑月严寒，火只占全盘 5%，按调候改取火为用神，木降为喜神；水为寒气来源，不列入喜神。"
  ]
}
```
`basis` 由代码按模板拼出（不交给大模型），模板变量只能来自排盘数据。

只用**用神 + 第一喜神**两个五行出建议，忌神只用于“少用”提示，不做恐吓。

| 五行 | 颜色 | 方位 | 数字（河图） | 行业方向（举例，不超过 5 个） | 季节 |
|---|---|---|---|---|---|
| 木 | 绿、青 | 东 | 3、8 | 教育、出版、设计、园艺/农林、医药健康服务 | 春 |
| 火 | 红、紫、橙 | 南 | 2、7 | 互联网/传媒、能源、餐饮、演艺、美业 | 夏 |
| 土 | 黄、棕、米色 | 中/本地、东北、西南 | 5、0 | 房地产/建筑、农业、仓储物流、行政管理、咨询 | 四季末 |
| 金 | 白、金、银 | 西 | 4、9 | 金融、法律、机械/制造、IT 硬件、精密技术 | 秋 |

- 出处：五行配色、方位、季节为通行说法（《尚书·洪范》五行、河图数）；行业分类为现代通行引申，**流派差异很大**，报告措辞必须用“可以优先考虑”“倾向于”，不能写“只能做”“必须做”。

## 9. 自检清单（代码单元测试要覆盖）

1. 用、喜、忌、闲互不重复，并集 = 五行。
2. 偏弱命局：用神 ∈ {印, 比劫}（或调候覆盖后为调候五行）。
3. 偏旺命局：用神 ∈ {食伤, 财, 官杀}（或调候覆盖后为调候五行）。
4. 特殊格局：忌神必须包含印（从弱各类）或财、官杀（专旺/从强）。
5. 每个结论都有 rules_hit 和 basis。
6. cases.json 全部案例的 yong / xi / ji 与期望一致。
