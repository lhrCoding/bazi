# strength.md —— 日主旺衰判断（计分法 v1）

> 版本：v2（2026-10-29，mingli-expert）。v2 只改了第 5 节“时辰扫描”（早晚子时派下扫 13 个时柱、置信度阈值改为比例），计分参数与 v1 完全相同。
> 输入：calendar.md 排出的四柱（或三柱）。输出：五行力量、十神分组力量、同党比例 S、旺衰等级、特殊格局候选、触发规则编号。
> 流派基础：子平法“得令、得地、得势”（《子平真诠》论用神先看月令；《滴天髓》论通根、旺衰），量化方式是本项目为了“同样输入永远同样输出”而设定的工程化版本，**不是**任何一本古籍的原文算法。参数已用 19 个标准案例人工核对（见 cases.json）。
> 规则编号以 `S-` 开头。

## 1. 基础对照表

### 1.1 天干五行
```
甲乙=木  丙丁=火  戊己=土  庚辛=金  壬癸=水
```

### 1.2 地支藏干与比例（S-HIDE）
比例依据“月令人元司令”天数的简化（本气为主，中气、余气递减），各支合计 = 1.0：

```json
{
  "子": [["癸",1.0]],
  "丑": [["己",0.6],["癸",0.3],["辛",0.1]],
  "寅": [["甲",0.6],["丙",0.3],["戊",0.1]],
  "卯": [["乙",1.0]],
  "辰": [["戊",0.6],["乙",0.3],["癸",0.1]],
  "巳": [["丙",0.6],["庚",0.3],["戊",0.1]],
  "午": [["丁",0.7],["己",0.3]],
  "未": [["己",0.6],["丁",0.3],["乙",0.1]],
  "申": [["庚",0.6],["壬",0.3],["戊",0.1]],
  "酉": [["辛",1.0]],
  "戌": [["戊",0.6],["辛",0.3],["丁",0.1]],
  "亥": [["壬",0.7],["甲",0.3]]
}
```
- 列表第一个是**本气**，比例 ≥ 0.3 的称“本气/中气”，0.1 的称“余气”。下文“有根”只认本气、中气（比例 ≥ 0.3）。
- 争议说明：四库（辰戌丑未）中气、余气的叫法各书不一（如辰中乙、癸谁算中气）。本项目按司令天数给比例（辰中乙木 9 天 > 癸水 3 天），所以辰中乙 0.3、癸 0.1。

### 1.3 十神分组（以日主五行为“我”）
| 分组 | 关系 | 同党/异党 |
|---|---|---|
| 比劫 | 与我同五行 | 同党 |
| 印 | 生我 | 同党 |
| 食伤 | 我生 | 异党 |
| 财 | 我克 | 异党 |
| 官杀 | 克我 | 异党 |

五行相生：木→火→土→金→水→木；相克：木克土、土克水、水克火、火克金、金克木。

## 2. 五行力量计分（S-POWER）

### 2.1 位置权重
```json
{
  "stem":   {"year": 0.8, "month": 1.0, "day": 0, "hour": 1.0},
  "branch": {"year": 0.8, "month": 3.0, "day": 1.5, "hour": 1.0}
}
```
- **日干本身不计分**（它是被评估的对象）。
- 月支 3.0：月令是旺衰第一要素（《子平真诠》“八字用神，专求月令”），约占全盘 1/3。
- 日支 1.5：日主坐下，贴身。年柱 0.8：离日主最远（《滴天髓》重“紧贴”）。
- 四柱总权重 = 0.8+1.0+1.0 + 0.8+3.0+1.5+1.0 = 9.1；三柱（无时辰）= 7.1。

### 2.2 计算步骤
```
power = {木:0, 火:0, 土:0, 金:0, 水:0}

# ① 天干（年、月、时；不含日干）
for 每个天干 g（位置 p）:
    w = stem[p]
    if g 的五行 在四柱地支的所有藏干（含余气）里都没有出现:   # S-ROOT 天干无根
        w = w × 0.6
    power[五行(g)] += w

# ② 地支藏干
for 每个地支 b（位置 p）:
    for (藏干 h, 比例 r) in HIDE[b]:
        power[五行(h)] += branch[p] × r

# ③ 合局加成（S-COMBO）——只在“三支全见”时加分，不做“化气”替换
三会方：寅卯辰→木、巳午未→火、申酉戌→金、亥子丑→水        +2.0
三合局：申子辰→水、亥卯未→木、寅午戌→火、巳酉丑→金        +1.5
（四柱地支集合包含这三个支即算，位置不限；三会、三合可同时成立，各加各的）

total = Σ power
```

### 2.3 v1 不计入分数的关系（只记录，供报告文字使用）
天干五合、地支六合、半合、拱合、六冲、三刑、六害、破。
理由：合化是否成立、冲是否“冲散”争议极大，各派条件不同，硬编码容易制造错误结论；v1 先保证主干稳定。报告里可以提“日支与月支相冲，环境变动多”这类描述，但不改变旺衰分数。v2 若要加入，需先补充案例。

## 3. 同党比例与得令/得地/得势

```
比劫力量 = power[日主五行]
印力量   = power[生日主的五行]
S = (比劫力量 + 印力量) / total            # 0 ~ 1，内部用浮点，不要先四舍五入
```

三个“得”只用于**展示和解释**，不参与等级判定（等级只看 S 和特殊格局条件）：
| 字段 | 定义 |
|---|---|
| `de_ling` 得令 | 月支本气是比劫或印 |
| `de_di` 得地 | 任一地支的本气/中气含比劫（有根），或任一地支本气是印 |
| `de_shi` 得势 | 年、月、时三干中比劫+印的个数（0–3） |

> 为什么不用“三得满足两个即旺”的老口诀：它无法区分程度，也解释不了“得令却身弱”（如案例 C01，戊土生丑月得令，但被金、水、木三方消耗）。S 值能给出连续的程度，口诀作为解释文字保留。

## 4. 旺衰等级（S-LEVEL）

判定顺序（**严格按顺序，命中即停**）：

```
① 若有时柱 且 S < 0.20 且 满足【从弱条件】      → level = "从弱"，special = 从财/从杀/从儿/从势
② 若有时柱 且 S ≥ 0.80 且 满足【专旺/从强条件】 → level = "从强"，special = 专旺/从强
③ S ≥ 0.50                                    → "身旺"
④ 0.45 ≤ S < 0.50                             → "中和偏旺"
⑤ 0.40 ≤ S < 0.45                             → "中和偏弱"
⑥ 否则                                         → "身弱"
```

阈值来由：随机抽样 3,000 个 1950–2010 年的出生时刻，S 的中位数约 0.40（两个同党五行 / 五个五行 的自然期望值）。按以上阈值，大致分布为：身弱 50%、中和 18%、身旺 29%、特殊格局 3%。中和带定在中位数附近 ±0.05 再偏上 0.05，是因为异党三方彼此也有生克，同党略少于一半时日主仍能“担得住”。

### 4.1 从弱条件（S-CONG）——宁严勿宽
全部满足才算：
1. S < 0.20；
2. 日主在四个地支里**没有本气/中气的根**（余气根不算）；
3. 四个地支里没有本气/中气的**印**；
4. 年、月、时三干没有比劫、印（`de_shi == 0`）；
5. 必须有时柱（三柱不判从格，时柱可能带根破格）。

子类型：看异党三方（食伤、财、官杀）中力量最大的一方 X：
- X ≥ 异党总和的 50% → X=财 “从财”，X=官杀 “从杀”，X=食伤 “从儿”；
- 否则 → “从势”。
- 并列时优先级：财 > 官杀 > 食伤。

出处与取舍：从格出自《滴天髓》“从象”、《子平真诠》论“弃命从财/从杀”。真从、假从（日主有微根仍从）争议很大。**本项目只认“真从”**：日主连本气、中气根都没有才算从。理由：误判从格会让喜忌整体颠倒，代价远大于把假从当身弱处理。不满足的极弱命局（如 C03、C07）按普通“身弱”走扶抑。

### 4.2 专旺/从强条件（S-ZHUANWANG）
全部满足才算：
1. S ≥ 0.80；
2. 得令（`de_ling == true`）；
3. 官杀力量 < total × 5%，且年、月、时三干无官杀透出；
4. 财力量 < total × 10%；
5. 必须有时柱。

子类型：比劫力量 ≥ 印力量 → “专旺”（一行得气：甲乙曲直、丙丁炎上、戊己稼穑、庚辛从革、壬癸润下，报告中可用这些名称）；否则 → “从强”（印多）。

### 4.3 并列与精度
- 比较一律用未四舍五入的浮点数；输出时 S 保留 3 位小数，power 保留 2 位。
- 若 S 与任一阈值相差 < 0.01，输出 `borderline: true`，报告措辞用“偏……”而非“明显……”。

## 5. 不知道时辰（三柱）（S-NOHOUR）

1. 用三柱直接计分（总权重 7.1），按第 4 节 ③–⑥ 定等级；**不判从弱、专旺**（即使 S 极端，也只标“身弱（极弱）”或“身旺（极旺）”，并在 `notes` 写明“时辰未知，未判断特殊格局”）。
2. **时辰扫描（v2：13 个时柱）**：早晚子时派下，一个公历日期内有 13 种可能的时柱——早子（00:00–00:59，按当日日干五鼠遁）、丑、寅……亥（按当日日干）、晚子（23:00–23:59，按**次日**日干五鼠遁，见 calendar.md CAL-DH-ZI）。把 13 个时柱分别补到三柱上，按四柱规则各算一次（这里允许判从格），统计：
   - `scan_slots`：扫描个数（有时柱信息缺失时固定为 13）
   - `direction_agree`：方向一致的个数（偏弱组 = 身弱/中和偏弱/从弱；偏旺组 = 身旺/中和偏旺/从强）
   - `yong_agree`：用神五行一致的个数
   - 扫描时年柱、月柱一律用三柱的默认值（当天 12:00），交节日的另一组年月柱由第 5 条单独处理。
3. 置信度（v2 改为比例，避免扫描个数变化时阈值失真；对 12 个时柱时与 v1 的 10/9/8 完全等价）：
   | 置信 | 条件 | 13 个时柱时等价于 | 免费页措辞 |
   |---|---|---|---|
   | 高 | direction_agree / scan_slots ≥ 0.80 且 yong_agree / scan_slots ≥ 0.75 | 方向 ≥ 11 且 用神 ≥ 10 | 正常显示 |
   | 中 | direction_agree / scan_slots ≥ 0.65 | 方向 ≥ 9 | “时辰未知，此结论大概率成立” |
   | 低 | 其余 | — | “时辰未知，此项仅供参考” |
4. 若扫描中有任何时辰会成为从格，在 `notes` 写出“若出生于 X 时、Y 时，可能为从格，喜忌会相反”，付费页提示。
5. **交节日降级**：若出生日当天有“节”交接（calendar.md CAL-NOHOUR，年月柱有两种可能），对另一组年月柱也算一次三柱结论；若两组的方向（偏弱/偏旺）或用神不同，置信度直接定为“低”，并把两种结论都写进 `notes`。

案例（v2，13 个时柱）：C18（高置信，13 个全部偏弱、10 个用水；新增的晚子戊子时为身弱、用水）、C19（立春当天：扫描方向 9/13 本应为“中”，但交节后的另一组年月柱结论为身旺用水，与交节前相反 → 降为“低”；新增的晚子甲子时为身弱、用火）。

## 6. 五行强弱图的数据（给前端）

- 图上展示的是“全盘五行占比”，用户会期望看到自己的日主那一格，所以**展示用数据 = power + 日干五行加 1.0**，再归一到 100%。
- S 仍按第 3 节（不含日干）计算。两者用途不同，前端字段分开：`power_display_pct`（图）、`power`（规则用）。
- 图上标注日主所在五行，并在图下写一句：“同党（帮扶你的力量）占 x%，异党（消耗你的力量）占 y%”。这里的 x = S×100。

## 8. 已知局限（写进报告的“方法说明”里，诚实告诉用户）

1. 不计合化、刑冲对力量的影响（v1）。
2. 季节对天干的影响只通过“月支权重 + 天干是否有根”间接体现。
3. 真假从格只认真从。
3a. 神煞（含 shensha.md 中展示的吉神）、纳音、空亡一律不参与旺衰计分。
4. 以上参数可以改，改动后必须重跑 cases.json 全部案例，并逐条记录结论变化。
