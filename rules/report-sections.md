## 3. 槽位定义（R-SLOT）

每章由若干**槽位**（slot）按固定顺序组成，每个槽位从素材库里选 0～N 条素材。表头含义：

- **必需**：Y = 每份报告都必须有内容（覆盖率测试强制，§5）；N = 条件命中才出现。
- **维度**：覆盖率测试要穷举的字段组合。该槽位素材的 `when` 只允许引用维度字段 + 该槽位声明的修饰字段（texts/README.md §4.4）。
- **依据模板**：引擎在段末追加的小字“依据：……”，由槽位定义、从 ctx 取值，**不由素材提供**，保证依据永远指向真实数据。
- **润色**：是否允许可选的大模型润色接口改写（§9），接口默认整体关闭。
- **无时辰**：三柱时的处理（§4）。

槽位 id 是代码与素材之间的契约：代码里的槽位配置必须与本节表格的 id 一一对应（加一条测试：解析本文件中 `| CH` 开头的表格行，与代码配置比对）。

## 8. 评分规则（代码计算；素材只按 tier / tier_group 选择）

### 8.1 大运（R-YUN-SCORE）
```
五行分 v(e) = 用神 +2；喜神 +1；闲神 0；第一忌神 −2；其余忌神 −1
大运分 = 0.4 × v(天干五行) + 0.6 × Σ_{地支藏干}( 藏干比例 × v(藏干五行) )
```
| 分数 | tier（对外标签） | tier_group |
|---|---|---|
| ≥ 1.2 | 顺势期 | 好 |
| 0.4 ～ 1.2 | 向好 | 好 |
| −0.4 ～ 0.4 | 平稳 | 平 |
| −1.2 ～ −0.4 | 宜稳守 | 守 |
| < −1.2 | 宜保守、打基础 | 守 |

### 8.2 流年（R-LN-SCORE）
- 年份范围：报告生成时所在的干支年（以立春为界）起连续 5 年。
```
self      = 0.4 × v(流年天干五行) + 0.6 × Σ( 藏干比例 × v(藏干五行) )
relation  = 流年支冲日支 −0.3；冲月支 −0.2；与日支六合 +0.2（可叠加；其余冲合只记录不加分）
score     = 0.5 × self + 0.3 × 所在大运分 + relation
```
- tier 阈值同大运。流年跨两步大运时，用立春当天所在的大运。
- 吉神不参与任何评分。
