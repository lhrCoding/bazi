读取 CLAUDE.md、docs/PRD.md、docs/ARCHITECTURE.md，输出 docs/UI.md 和 design/ 目录下可直接用浏览器打开的 HTML 原型。

要设计的页面：
1. 首页：极简，一屏内完成输入（出生日期、时辰、性别、出生地可选），一个按钮
2. 免费结果页：只展示喜忌等少量内容（具体范围以 PRD 为准）+ 付费引导
3. 付费页：单档 ¥9.9（暂定），清楚写出完整报告包含什么
4. 付费报告页：这是产品的核心卖点，要像一份精心排版的「命书」，而不是聊天记录
   （例如：命盘总览、五行雷达图、大运时间轴、逐年流年卡片、分领域建议）

视觉方向：东方、克制、有质感（宣纸底色、朱砂红点缀、宋体/楷体标题），避免廉价的玄学风（发光八卦、紫色星空）。
手机优先，大部分用户会在手机上打开。
完成后停下，告诉用户在哪里打开原型预览。
