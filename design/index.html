知命界面原型

「一元知命」（暂名，待改名）· 第 4 步 UI 设计 · 2026-10-29 · 规范见 docs/UI.md
纯静态 HTML + 内联 CSS，不加载任何外部资源。手机优先：建议用浏览器开发者工具切到 iPhone（375×812）预览，或直接在手机上打开。示例命盘为 rules/cases.json 的 C11（1981-10-27 11:28 男，戊寅日主，身旺，用金喜水）。

主流程

1首页

一屏完成输入：公历/农历、年月日、时分或「不知道」、性别、出生地（可选）、一个按钮。

home.html 2免费结果页

四柱、五行强弱、日主旺衰、喜用/忌神 + 固定文案付费引导。右上角可切换无时辰、交节日、已校正等状态。

result.html 3付费与支付

所有手机环境先出同一个确认面板（微信内为微信支付，其他浏览器为支付宝 / 到微信中打开），电脑扫码；支付中 / 成功 / 未完成 / 超时 / 关闭。

pay.html 4付费报告「命书」

封面、目录、第〇至第八章、3 张图、5 张逐年卡片、依据标注、保存提示；可切换「长图版式」。

report.html

辅助页面

报告访问与异常状态

加载中、链接无效或未支付（统一页）、链接不完整、网络错误、输入无法排盘、404。

status.html 隐私说明 · 免责声明 · 联系

写明服务器保存的全部字段、链接仅编码未加密的风险、退款方式。

字体

宋体标题 · 命书 · 戊寅 辛酉

楷体引文 · 戊土固重，既中且正。

黑体界面与说明文字 · 一次付清，没有会员和续费。

原型只用系统字体。macOS 上能看到宋体和楷体；iPhone 与安卓上中文衬线字体是否可用要看系统（未核实），没有时会退回黑体。版式层级靠字号、字重、颜色和留白，不依赖字体本身。已确认（2026-10-29）：正式版本站自托管思源宋体子集，只收固定字（见 UI.md §2.2），原型仍用系统字体示意。
