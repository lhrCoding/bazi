## Q1（T16，2026-10-30）strength.md §4.3 borderline 的「任一阈值」是否包含 0.20 / 0.80

> **已裁定（用户 2026-11-11）**：按当前实现，已写入 strength.md §4.3（v2.2）。

- 现状：§4.3 写「若 S 与任一阈值相差 < 0.01，输出 `borderline: true`」。§4 判定顺序里出现的 S 阈值有 0.20（从弱）、0.80（专旺 / 从强）、0.50、0.45、0.40 五个。
- T16 实现：只按普通等级阈值 **0.50 / 0.45 / 0.40** 判 borderline（代码 `isBorderline`，`rules/strength-level.ts`）。
  理由：0.20 / 0.80 只有在从格其余 4 条都满足时才会改变结论；对多数命盘（如 S = 0.195 但有根的身弱）标 borderline 会让报告写成「偏身弱」，与「极弱」不符。
- 影响：cases.json 20 个案例无一落在 0.20 / 0.80 的 ±0.01 内，两种读法下结果相同，测试不受影响。
- 请裁定：维持现状；或改为五个阈值都算；或「0.20 / 0.80 仅在其余从格条件都满足时算」。裁定后在 strength.md §4.3 写明。
