# PRD v0.4 —— 极简算命网站「一元知命」（暂名，需改名）

> 状态：v0.4。按 2026-10-29 用户确认的决定更新：付费报告改为「素材库拼装」，运行时不接大模型；服务器只存订单，不存出生信息和报告；命理口径确定（见 4.4）。上线前置事项见 9.2，仍需决定的事项见 9.3。

## 1. 背景
很多人对八字感兴趣，但：
- 免费的 AI 聊天给出的结果空泛、每次问都不一样，没有可信度；
- 线下或线上找真人看，价格从几十到几百元，门槛高；
- 现有算命网站 / App 页面杂乱、入口繁多，收费以「会员 + 虚拟币」为主，用户付费前不知道总共要花多少钱。

**竞品调研结论（详见附录 A）：**
1. **排盘本身已经是免费的行业标配**：查八字、问真八字、大师八字等都把四柱、十神、藏干、大运、流年图表免费给出。
2. **主流付费方式是会员订阅 + 虚拟币**：会员 ¥25～¥40/月、¥98/季、¥158～¥258/年；虚拟币从 ¥6、¥18 一档起充。对「只想看一份自己的报告」的小白用户门槛高、心理负担重（总价不清楚、担心自动续费）。
3. **报告的卖点是「量」**：查八字宣称 AI 报告超过 2 万字、超过 100 组图表。大量文字未必有用，我们的切入点是更短、更结构化、有年份时间线和依据。
4. **专业工具（问真、大师八字）的用户是命理爱好者**，界面密集、术语多，不适合只想图个参考的小白。

机会：一个**干净、快、便宜、结果稳定且专业**的网站。**只卖一份 ¥9.9 的完整报告，价格写在按钮上，一次付清**；不做会员、不做虚拟币，完成冲动消费。报告文字**全部来自人工审核过的素材库**，运行时不调用大模型，同一命盘的报告逐字一致。

## 2. 目标用户
- 18-40 岁，对传统文化 / 玄学感兴趣，手机为主
- 动机：好奇、娱乐、遇到选择时想要一点参考（换工作、感情、择业）
- 付费心理：¥9.9 属于「一杯奶茶以下」的冲动消费区间，但需要看到「明显值」。竞品报告 / 会员的起步价在 ¥18～¥40 一档，¥9.9 一份完整报告有明显价格优势
- **不是**我们的目标用户：每天排盘研究的命理爱好者（他们用问真 / 大师八字这类专业工具）

## 3. 核心流程
```
首页输入出生信息（10 秒内完成）
  → 免费结果页（1 秒内出结果；服务器不保存出生信息）
      只有：四柱八字 + 五行强弱图 + 日主旺衰 + 喜用神 / 忌神 + 付费引导
      （不含性格画像、不含吉神）
      未选出生地时注明「未校正真太阳时」
  → 付费引导（一个按钮：「¥9.9 查看完整报告」，总价一次说清）
      完整报告：一句话性格画像 + 详细喜忌解读 + 性格与天赋 + 吉神说明 + 适合的行业 / 颜色 / 方位 / 数字
               + 十年大运 + 未来 3-5 年逐年流年 + 事业 / 财运 / 感情 / 健康分领域分析
      不知道时辰的用户：按钮旁写明「无时辰，报告不含时柱相关分析」，价格不变
  → 创建订单（服务器只记：订单号、金额、状态、时间、出生信息的加盐哈希指纹）
  → 支付（微信支付 / 支付宝）
  → 报告页：链接 = 编码后的出生信息 + 订单号
      打开时服务器核对「订单已付款」且「出生信息指纹匹配」→ 即时现算报告（不排队、不存报告）
      页面醒目提示：链接丢失无法找回，请收藏链接或保存为长图
```

### 3.1 报告是怎么来的（素材库拼装）
1. **离线**：命理专家按 `rules/` 的结论类型起草约 300～600 段文字素材，每段挂触发条件（如「日主偏弱 + 喜木火」「某年流年冲日支」）；同一条件准备 2～3 个版本。按批提交，用户每批随机抽检 10% 后批准整批，批准后存进仓库，和代码一起版本管理。
2. **运行时**：确定性代码根据排盘结果和规则结论，选中触发的素材；同一条件有多个版本时，按命盘确定性选一个（例如对命盘做哈希取模），保证同输入同输出、不同命盘读起来不千篇一律。素材中的年份、干支等变量由代码填入。
3. **古籍引用**：可引用公共领域古籍原文（如《滴天髓》《穷通宝鉴》《子平真诠》等原文）作为卖点；**现代注释、白话译本不得照搬**，白话解释由我们自己撰写。
4. **大模型润色**：预留可选接口，**默认关闭，MVP 不启用**。

### 4.4 命理口径（细节以 `rules/` 为准）
- **子时**：采用早晚子时派。23:00–24:00 为晚子时，日柱仍算当日；00:00–01:00 为早子时，日柱算次日。
- **格局**：只认真从格，不认假从格；不满足真从条件的按正格（扶抑）处理。
- **真太阳时**：仅在用户选了出生地时校正；未选时按北京时间排盘，结果页和报告页注明「未校正真太阳时」。
- **神煞**：只展示吉神（如天乙贵人、文昌等，具体列表以 `rules/` 为准），**日干、年干都查**；吉神**只在付费报告中展示，免费页不展示**；**不展示凶煞、纳音、空亡**。

### P1（上线后看数据再做）
- 付费引导区展示「付费内容目录预览」（每章标题 + 一句摘要），用于提高转化，需 A/B 验证
- 报告导出 PDF（长图已在 P0）
- 链接找回：用户重新输入出生信息 + 支付账单里的商户订单号，用已存的指纹核对，匹配即可重新打开（不多存任何数据；2026-10-29 用户确认放 P1）
- 启用大模型润色（接口已预留；启用前需重新评估成本、合规登记和「同输入同报告」承诺）
- 分享裂变（分享给朋友后解锁某一章节）
- 合婚 / 两人合盘（竞品普遍有，是常见的第二次消费点）
- 起名建议

### P2（以后再说）
- 两档定价（如低价尝鲜档 + 完整档），在 ¥9.9 单档跑出转化数据后再评估
- 「不知道时辰」引导估算时辰
- 账号体系、历史记录
- 真人命理师复核（高价档）
- 小程序版本
- 流年单年报告（每年年初的复购点）

## 5. 付费设计
### 5.1 定价与内容
| 档位 | 价格 | 内容 | 定位 |
|---|---|---|---|
| 免费 | ¥0 | 四柱、五行强弱图、日主旺衰、喜用 / 忌神（不含性格画像、吉神） | 证明「我们算得准、很专业」，对标竞品的免费排盘 |
| 完整报告 | ¥9.9 | 一句话性格画像、详细喜忌解读、性格与天赋、适合的行业 / 颜色 / 方位 / 数字、十年大运、未来 3-5 年逐年流年、事业 / 财运 / 感情 / 健康分领域分析、吉神说明 | 唯一收入来源。竞品报告 / 会员起步 ¥18～¥40，¥9.9 有明显价格优势 |

- 不知道时辰：只排三柱，价格不变；付费按钮旁明确写出报告不含哪些内容（时柱相关分析、子女 / 晚年等依赖时柱的判断）。

### 5.2 付费原则（写进产品，也写在页面上）
1. **一次付清、没有后续加价**：只有一个付费项，买完就是全部内容，报告页里没有任何追加付费按钮。
2. **不做会员、不做虚拟币、不做自动续费**：竞品主要靠会员和虚拟币收费，我们反着来，这也是卖点。
3. **价格写在按钮上**：「¥9.9 查看完整报告」，不写「立即解锁」这类不说价格的按钮。
4. **不用营销话术**：不写假的倒计时、划线原价、「已有 xx 万人测算」。

### 5.3 报告的「值」怎么体现
- 篇幅目标 5,000～8,000 字（以素材拼装实际能达到的为准），手机上读得完
- 3～4 张图表（命盘图、五行图、大运时间轴等）+ 逐年卡片
- 每条结论标注规则依据；具体到年份的提示和建议
- 每段文字都经过人工审核；适当引用古籍原文并注明出处
- 不和竞品比字数，比的是结构清楚、能具体用上

### 5.4 支付与售后
- 经营主体：个体工商户；支付渠道：微信支付 / 支付宝商户（类目审核风险见 9.2）
- 报告即时现算，不存在「生成失败」流程；若已付款但报告页打不开（如校验异常），用户可联系人工处理
- 用户主动退款：MVP 阶段人工处理（页面留联系方式），每单记录退款原因
- 链接丢失：MVP 无法找回（服务器不存出生信息），付款后和报告页都要明确提示保存

## 6. 差异化：为什么「和普通 AI / 竞品不一样」
| 普通 AI 聊天 / 现有竞品 | 我们 |
|---|---|
| 大模型凭感觉「算」八字，经常排错 | 代码精确排盘，节气精确到分钟，选了出生地可校正真太阳时 |
| 同样问题问两次，答案不一样 | 同样生日，报告文字逐字一致（规则引擎 + 确定性素材选择） |
| AI 现场生成，可能胡编、口径前后矛盾 | 每段文字由命理专家起草、人工审核后入库；运行时不调用大模型 |
| 一大段泛泛而谈的文字；或者堆到 2 万字 | 结构化报告：命盘图、五行图、大运时间轴、逐年卡片 |
| 结论没有依据 | 每条结论标注依据（如「因日主甲木生于酉月，失令……」），可引用古籍原文 |
| 说的都是「你很善良、有时犹豫」 | 具体到年份的提示和可执行建议 |
| 会员 + 虚拟币，总价不清楚，担心自动续费 | 只有一个 ¥9.9 付费项，一次付清，无续费、无追加 |
| 要注册登录，个人信息存在别人服务器上 | 不登录、不存出生日期、不存报告 |
| 专业工具界面密集、术语多 | 首页只有一个表单，小白也能 10 秒填完 |

## 7. 不做什么（MVP）
- 不做登录 / 会员 / 虚拟币 / 自动续费
- 不做多档定价（单档 ¥9.9）
- 运行时不调用大模型（润色接口预留但默认关闭）
- 不存出生日期、不存报告内容；不提供链接找回（找回放 P1）
- 不对链接中的出生信息加密（只编码，用户已确认）
- 不展示凶煞、纳音、空亡；不认假从格
- 不做紫微斗数、星座、塔罗、六爻等其他体系
- 不做真人咨询
- 不做医疗、投资、法律方面的断言；不写恐吓性内容；不卖「化解」「开运物品」
- 不做层层加价、假倒计时、假划线价、假测算人数
- 不照搬现代注释 / 白话译本
- 不做 App（只做手机网页）

- **个人信息保护**：虽然不存出生日期，但出生信息哈希指纹和链接中的出生信息仍属于个人信息处理，需有隐私说明。链接中的出生信息**仅编码、未加密**（用户已确认），被转发 / 截图即可看出生日，隐私说明和报告页需如实告知并提示勿公开分享；服务器侧保证出生信息不进日志。具体是否需要额外手续建议咨询。
